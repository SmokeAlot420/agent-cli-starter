Show or modify configuration settings.

$ARGUMENTS

Current settings:
- model: Current AI model
- permission: Permission mode (normal/acceptEdits/plan)
- thinking: Extended thinking (on/off)
- verbose: Verbose output (on/off)
- mcp: MCP servers enabled

Commands:
- `/config` - Show all settings
- `/config <setting>` - Show specific setting
- `/config <setting> <value>` - Change setting
