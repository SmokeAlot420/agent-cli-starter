---

Create a detailed implementation plan for the following:

$ARGUMENTS

Think through:
1. What components/files need to be created or modified
2. What's the right order of implementation
3. What tests should be written
4. What potential issues might arise

Structure your plan with:
- **Overview**: Brief summary of what we're building
- **Files to Create/Modify**: List each file with its purpose
- **Implementation Steps**: Numbered steps in order of execution
- **Testing Strategy**: How to validate the implementation
- **Risks & Mitigations**: Potential issues and how to handle them

Be thorough but concise. Focus on actionable steps.
