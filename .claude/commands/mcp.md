description: Show MCP server status and manage servers
argument-hint: "[add|remove|status] [server-name]"

Show MCP (Model Context Protocol) server status.

$ARGUMENTS

If no arguments provided, show all configured MCP servers and their status.

Commands:
- `/mcp` - Show all MCP servers
- `/mcp status` - Same as above
- `/mcp add <name> <config>` - Add a new MCP server
- `/mcp remove <name>` - Remove an MCP server
