View or edit CLAUDE.md memory configuration files.

$ARGUMENTS

Memory file locations:
- User memory: ~/.claude/CLAUDE.md (persistent across projects)
- Project memory: ./CLAUDE.md (project-specific)

Commands:
- `/memory` - Show all memory files
- `/memory user` - Show user memory
- `/memory project` - Show project memory
